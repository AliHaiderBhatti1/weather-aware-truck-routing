# Deployment guide

Target: **Vercel** (web) + **Render** (API, Docker) + **Neon** (Postgres). All free tiers, no card needed.

> Deploy from `main`. When `dev` is ready: `git checkout main && git merge --ff-only dev && git push`.

## 1. Neon (database, 2 min)

1. neon.tech → sign in with GitHub → **New project** (any name, region close to Render's Oregon).
2. Copy the **connection string** (starts with `postgresql://`). Make sure it ends with `?sslmode=require`.

## 2. Render (API, 5 min)

1. render.com → sign in with GitHub → **New +** → **Blueprint** → pick this repo. Render reads `render.yaml`.
2. When prompted for the unsynced environment variables:
   - `MAPBOX_ACCESS_TOKEN` – your token
   - `DATABASE_URL` – the Neon string
   - `CORS_ALLOWED_ORIGINS` – leave empty for now; fill in after Vercel gives you a URL
3. Click **Apply**. First build takes ~3 min. Note the service URL, e.g. `https://weather-truck-routing-api.onrender.com`.
4. Check `https://<your-api>.onrender.com/api/health/` returns `{"status":"ok"}`.

## 3. Vercel (web, 3 min)

1. vercel.com → **Add New… → Project** → import the repo.
2. **Root Directory:** `frontend`. Framework preset: Vite (auto-detected from `vercel.json`).
3. **Environment variables:** `VITE_API_BASE_URL` = `https://<your-api>.onrender.com` (no trailing slash).
4. Deploy. Note the production URL, e.g. `https://weather-aware-truck-routing.vercel.app`.

## 4. Close the loop

1. Back in Render → your service → **Environment** → set `CORS_ALLOWED_ORIGINS` to the Vercel URL, and `DJANGO_CSRF_TRUSTED_ORIGINS` to the same. Save (Render redeploys).
2. Open the Vercel URL and plan a trip.

## 5. Keep the free API awake (optional, 2 min)

Render's free tier sleeps after 15 min idle (~50 s cold start). cron-job.org → create a job hitting `https://<your-api>.onrender.com/api/health/` every 10 minutes.

## Environment variables reference

| Variable | Where | Notes |
|---|---|---|
| `MAPBOX_ACCESS_TOKEN` | Render | Public `pk.` token is fine; restrict it to your domains in Mapbox. |
| `DATABASE_URL` | Render | Neon connection string. Falls back to SQLite if unset (data lost on redeploy). |
| `DJANGO_SECRET_KEY` | Render | Generated by the blueprint. |
| `DJANGO_ALLOWED_HOSTS` | Render | `.onrender.com` by default. |
| `CORS_ALLOWED_ORIGINS` | Render | Your Vercel URL(s), comma separated. Preview deploys are allowed by regex. |
| `VITE_API_BASE_URL` | Vercel | The Render URL. |
| `VITE_MAP_STYLE_URL` | Vercel (optional) | Any MapLibre style URL; defaults to CARTO Positron. |
